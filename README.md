# CompoForm

Conception de moules composites (fibre de verre / carbone) à partir de fichiers STL, 3MF, OBJ ou STEP, directement dans le navigateur : les fichiers ne quittent pas la machine.

**Application : https://tguillaume02.github.io/compoform/**

Ce dépôt contient uniquement la version publiée du site, générée automatiquement.
